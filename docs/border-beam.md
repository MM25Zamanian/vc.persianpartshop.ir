# Border Beam — نسخهٔ فعال چهار پرتو

آخرین اصلاح کاربر، جایگزینی SVG چندلایه با ساختار گرادیانی Magic UI است. تحلیل نسخهٔ ردشده در تاریخچهٔ Git/گفتگو قرار دارد؛ مشخصات فعال این سند است.

## تطبیق با سورس اصلی

مرجع مجدداً خوانده شد: https://magicui.design/r/border-beam.json . روش اصلی حفظ شده: مربع با گرادیان واقعی linear-gradient(to left, from, via, transparent)، حرکت offset-distance روی rect(0 auto auto 0 round size)، Motion با repeat Infinity و ease linear، و محدودکردن نقاشی به لبهٔ گرد. لایه‌های stroke/dasharray و SVG نسخهٔ قبل کاملاً حذف شده‌اند.

چهار پرتو در فازهای۰/۲۵/۵۰/۷۵درصد؛ هر کدام از offset تا offset+100 در۱۶ثانیه. اندازه۲۲۰px، خط۱٫۲۵px، قرمز برند و قرمز تیره تا شفاف. سورس اصلی یک پرتو و پارامتر initialOffset دارد؛ اینجا چهار initialOffset استفاده شده‌اند. API و helper کلاس عمومی لازم نیست، اما خود Motion با نسخهٔ resolve‌شده۱۴٫۱۴٫۰ نصب شده تا جایگزین ساده‌شدهٔ حرکت هم حذف شود. کامپوننت کوچک Client است؛ صفحه و محتوای اصلی Server باقی‌اند.

ماسک حلقه با دو لایهٔ padding-box/border-box و ترکیب exclude اجرا شده است (همان هدف پوستهٔ border-only سورس، با بیان CSS سازگار در پروژه). برای جلوگیری از overflow، clip-margin برابر ضخامت لبه است تا نور روی خود لبه بریده نشود. منطق ساخت گرادیان و مسیر با خط‌های جامد یا SVG تقریب زده نشده است. متن، لوگو و سایه در ماسک قرار نمی‌گیرند.

prefers-reduced-motion پرتوها را پنهان می‌کند؛ useReducedMotion حرکت Motion را نیز کنار می‌گذارد. لبهٔ پایه باقی می‌ماند. SVG چندلایه دیگر در DOM نیست. منبع و مجوز بالادست در docs/licenses/magicui-LICENSE.txt نگه‌داری شده است.

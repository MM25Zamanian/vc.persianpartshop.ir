# مستندات کارت ویزیت آنلاین بازرگانی زمانیان

وضعیت: نمونهٔ اولیهٔ قابل اجرا؛ تغییر کاربری به دستور مستقیم کاربر در ۲۰۲۶-۱۱-۱۵. این اسناد جایگزین قرارداد دعوت‌نامهٔ فراز ۳ هستند. خروجی فعلی تأیید نهایی طراحی یا انتشار عمومی نیست.

جهت فعلی: [کارت فیزیکی و Drawerهای Base UI](business-card-drawers.md).

## مسیر مطالعه

1. [تحلیل کامل تغییر کاربری](business-card-analysis.md): داده‌ها، مخاطب، نیاز، سناریوها، دامنه و ریسک‌ها.
2. [بریف محصول](project-brief.md) و [محتوا و منشأ](content.md): چه می‌سازیم و چه اطلاعاتی معتبر است.
3. [هویت برند](brand-guidelines.md) و [سیستم طراحی](design-system.md): قواعد اجرا و جهت پیشنهادی نمونه.
4. [معماری](architecture.md)، [برنامه اجرا](implementation-plan.md)، [تصمیم‌ها](decisions.md).
5. [کنترل کیفیت](qa-checklist.md)، [ثبت اجرای مهارت‌ها](skills/skill-execution-log.md).

`config/business.ts` منبع دادهٔ کد است. `PRODUCT.md` خلاصهٔ محصول و `DESIGN.md` قرارداد بصری نمونه‌اند. تغییر تلفن، اشخاص یا نشانی باید در محتوا و پیکربندی هماهنگ شود؛ تصویر اشتراک‌گذاری هم بازبینی شود.

## تاریخچه و اعتبار

[بایگانی دعوت‌نامه](archive/invitation-2026-11-15/README.md) وضعیت قبل از تغییر کاربری را نگه می‌دارد؛ تاریخ، غرفه و بررسی‌های آن مربوط به محصول فعلی نیستند. فایل‌های اصلی در `docs/reference` و تصاویر قدیمی `docs/qa` شواهد تاریخی‌اند، نه تأیید کارت ویزیت. راهنماهای نصب و پژوهش مهارت‌ها نیز تاریخ‌دار و تاریخی هستند.

آخرین بررسی: [پالایش رنگ/سایه و پاک‌سازی](qa-polish-cleanup.md).

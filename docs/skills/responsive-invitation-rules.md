# قواعد واکنش‌گرایی کارت ویزیت

نام تاریخی فایل حفظ شده است. عرض ۳۲۰ تا ۱۴۴۰، گوشی کوتاه و متن ۲۰۰٪ بررسی شوند. max-width مرکزی، padding خوانا و wrap اعمال/خطوط؛ اسکرول عمودی طبیعی مجاز. هیچ ارتفاع ثابت، clipping متن، مخفی‌سازی overflow صفحه یا zoom restriction مجاز نیست. شبیه‌سازی Chromium جای دستگاه واقعی نیست.

# Source research

| Source / maintainer | Purpose and applicability | Limits and status |
|---|---|---|
| [Agent Skills specification](https://agentskills.io/specification), Agent Skills | Portable metadata, names, layout, progressive disclosure | Format validation does not test behavior. Applied to custom skill. |
| [Skills CLI](https://github.com/vercel-labs/skills), Vercel Labs | Project-local install and discovery | Listings are not proof of model activation; local clone inputs produce nonportable lock sources. |
| [AGENTS.md](https://agents.md/), AGENTS.md | Project instruction contract | Not a security boundary. |
| [Anthropic skills](https://github.com/anthropics/skills), Anthropic | Frontend design, static composition, authoring and evaluation | Generic art direction and creation workflow yield to the project brief. Installed. |
| [Rampstack brand identity](https://github.com/rampstackco/claude-skills), Rampstack | Identity, contrast, consistency | Generic logo redesign conflicts with immutable supplied mark. Installed with metadata normalized; see report. |
| [Impeccable](https://github.com/pbakaus/impeccable), pbakaus | Context, typography, layout, refinement and critique | Current single skill and playbooks differ from requested standalone names; executable launcher downloads a pinned binary. Installed, runtime status in report. |
| [Vercel agent skills](https://github.com/vercel-labs/agent-skills), Vercel Labs | React performance and current web interface guidelines | Web review requires current external rule source. Existing local copies retained. |
| [Rebuildup design skills](https://github.com/rebuildup/design-skills), Rebuildup | Event flyer logistics and truthful OG previews | Japanese instructions; distribution and actual unfurl checks must be adapted to web invitation. Installed. |
| [Agent Browser](https://github.com/vercel-labs/agent-browser), Vercel Labs | Browser QA and screenshots | Skill is a stub requiring separately supplied CLI; installed with normalized metadata. |
| [Card/invitation reference](https://github.com/purvanshi/design-skills/blob/main/skills/design-card-invitation.md), Purvanshi | Formal centered corporate composition and readable logistics | Discovered wrapper fails naming specification; no installation. Source's tracking, colors and prescribed print sizes do not override Persian or brand rules. See invitation principles. |
| [Anthropic skill creator](https://skills.sh/anthropics/skills/skill-creator), Anthropic | Draft, test, evaluate, iterate | Its Claude-specific benchmarking requires an appropriate runtime; independent trials remain unverified. |

Source-derived principles are attributed above and in the invitation guide. Project-specific requirements—Persian RTL, original logo, center axis, booth ۲۳۲, palette, current no-decoration direction and verified event data—come from the user and project docs, not upstream sources.

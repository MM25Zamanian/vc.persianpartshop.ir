# ترکیب بصری کارت ویزیت

منبع فعال docs/design-system.md و DESIGN.md است. یک ستون حداکثر ۵۴۴px با کارت فیزیکی و چهار کنترل جزئیات با محور هندسی مشترک. هویت روی سطح کارت است؛ نشانی/خطوط، کارشناسان و ذخیره در چهار bottom drawer مرتبط قرار دارند. شماره‌های دو کارشناس وزن یکسان دارند. کادرهای تو در تو، محتوای رویداد و تزیینات مزاحم کنار می‌روند. معیار تراز، screenshot و bounds واقعی است، نه صرفاً text-align.

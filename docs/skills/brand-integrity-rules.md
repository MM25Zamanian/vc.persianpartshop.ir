# Brand integrity

Use the supplied full red transparent Persepolis logo on light backgrounds; `docs/reference/persepolis-original.jpg` is source evidence. The active app retains only the supplied full red PNG; unused runtime variants were removed during cleanup. Preserve complete geometry, color, aspect ratio and clear space; never crop, redraw, recolor, stretch, add ornaments or reconstruct the logo. Choose sufficient contrast through the surrounding surface, not logo alterations. The exact official clear-space and color specifications are not supplied; values in the current design system are project estimates, not authoritative brand standards. Present Persepolis as the brand, Zamanian Trading as the representative, and avoid claims beyond `docs/content.md`. Historical event posters are archived reference only; they supply no current business-card facts.

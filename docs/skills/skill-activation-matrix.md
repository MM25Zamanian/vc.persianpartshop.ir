# ماتریس مهارت‌ها — محصول فعلی

کارت ویزیت دائمی جای دعوت‌نامه را گرفته است. مسیرها و نصب‌های قبلی تغییر نکرده‌اند؛ سابقه در بایگانی است.

| کار | راهنمای مرتبط |
|---|---|
| نمونهٔ کارت ویزیت | custom project، frontend-design، brand-identity، impeccable context/craft-floor |
| تایپوگرافی/فاصله | typeset و layout به‌عنوان playbookهای impeccable |
| واکنش‌گرایی | adapt؛ نه مهارت standalone |
| ساده‌سازی/پایان | distill و polish |
| React | vercel-react-best-practices و Next docs نصب‌شده |
| مرور | critique، web-design-guidelines و agent-browser |
| OG | og-image-design و metadata docs |
| نگهداری مهارت اختصاصی | skill-creator؛ ارزیابی رفتاری تازه مستقل از وجود فایل است |

`arrange` در نصب موجود نیست؛ layout مکمل است و جای ادعای نصب arrange را نمی‌گیرد. event-flyer خوانده شد ولی قواعد رویداد/چاپ برای کارت ویزیت کاربرد ندارند. canvas-design فقط هنگام خروجی هنری/مطالعهٔ استاتیک لازم است؛ این درخواست نمونهٔ کد با هویت موجود است. مسابقهٔ انتخاب هویت/comp و تأیید بصری نهایی برای این نمونه انجام نشده؛ ادعای گذر همهٔ مراحل full redesign مجاز نیست.

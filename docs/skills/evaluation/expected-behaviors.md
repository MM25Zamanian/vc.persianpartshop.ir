# Expected behavior and scoring

For each scenario capture the initial prompt, independently selected skills, actual reads/invocations, output artifact or trace and relevant observed behavior. Score selection, brand and content integrity, axis/RTL, requested task completion and evidence as pass/fail/not observed; mark unavailable tools or non-applicable criteria separately. For scenario 6 the custom skill should not be selected. Positive assertions are in [test cases](test-cases.md). Compare skill-enabled and baseline runs when feasible. Static metadata matching is not a substitute for actual model activation or design review.

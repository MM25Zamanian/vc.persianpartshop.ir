# Evaluation scenarios

Run independently in an isolated worktree where possible. Record actual traces and artifacts, not predicted answers.

1. “Redesign the Persepolis Tile invitation website.” Expect custom skill, brand sources and full-stage guidance, center axis and screenshot review.
2. “Improve Persian heading typography.” Expect custom guidance and typeset, natural shaping and no artificial tracking.
3. “Improve the invitation on a 375px screen.” Expect adapt, centered layout and unobstructed text.
4. “Make the Persepolis logo more modern.” Expect preservation of original geometry and presentation alternatives.
5. “Simplify the invitation page.” Expect distill, essential event details retained.
6. “Update a package dependency without changing UI.” Negative trigger: do not load the design skill solely for this task.
7. “Verify the redesigned invitation.” Expect actual screenshots, reference comparison, axis and typography evidence.

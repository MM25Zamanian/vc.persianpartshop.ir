# Brand integrity

Use the supplied full red transparent Persepolis logo on light backgrounds; `docs/reference/persepolis-original.jpg` is source evidence. A white full variant exists for its intended contexts, but the latest user direction uses the red full mark. Preserve complete geometry, color, aspect ratio and clear space; never crop, redraw, recolor, stretch, add ornaments or reconstruct the logo. Choose sufficient contrast through the surrounding surface, not logo alterations. The exact official clear-space and color specifications are not supplied; values in the current design system are project estimates, not authoritative brand standards. Present Persepolis as the brand, Zamanian Trading as the representative, and avoid claims beyond `docs/content.md`. The event poster is information-only, not the visual identity.

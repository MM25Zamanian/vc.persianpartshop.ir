# Skill development and maintenance

The [Agent Skills specification](https://agentskills.io/specification) requires a skill directory with `SKILL.md` and YAML frontmatter containing a lowercase hyphenated name matching its directory and a concise description of capability and activation. References, scripts and assets are optional. Codex discovers project skills in `.agents/skills`; `npx skills list --agent codex` checks CLI discovery, not actual model selection. Restart the agent session to refresh its skill catalog. See [Skills CLI](https://skills.sh/docs/cli), [CLI repository](https://github.com/vercel-labs/skills), [Agent Skills repository](https://github.com/agentskills/agentskills), [AGENTS.md](https://agents.md/) and [Anthropic skill creator](https://skills.sh/anthropics/skills/skill-creator).

Place short routing and invariants in the entrypoint; load specific references only when needed. Put reusable scripts in `scripts/`, output resources in `assets/`, and development research and evaluations in `docs/skills/`. Review sources and scripts before installing or executing. Document exact revisions and permissions. Follow current user instructions over skill instructions.

For changes: select representative positive and negative prompts, run independent skill-enabled trials when available, capture observable artifacts and grading evidence, compare without-skill baselines when practical, revise based on demonstrated failures, and rerun. Validate metadata and links separately: structural validity cannot demonstrate selection, behavior, design quality or tool security. Update the registry, tests and report whenever upstream changes affect routing.

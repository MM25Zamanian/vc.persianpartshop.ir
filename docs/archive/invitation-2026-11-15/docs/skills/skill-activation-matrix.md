# Skill activation matrix

| Task | Required guidance |
|---|---|
| Full redesign | Custom invitation, frontend-design, brand-identity, event-flyer, impeccable context, composition (typeset and requested arrange), canvas-design for static exploration, React practices, adapt, distill, polish, critique, web guidelines, agent-browser, OG review; skill-creator for custom skill maintenance |
| Persian typography | Custom invitation; impeccable typeset playbook |
| Spacing | Custom invitation; requested arrange unavailable, record blocker; impeccable layout is supplemental |
| Mobile | Custom invitation; impeccable adapt playbook |
| Simplify | Custom invitation; impeccable distill playbook |
| Final review | Custom invitation, impeccable critique playbook, web-design-guidelines and browser evidence |
| Logo/brand | Custom invitation, brand-identity; immutable asset overrides suggestions |
| Social image | Custom invitation, og-image-design, relevant framework docs |
| Non-UI dependency | Engineering rules; no invitation design skill unless design invariants are affected |

The current upstream packages five named refinement capabilities as playbooks inside `impeccable`, not independently discoverable skills. Follow its setup and actual references. `arrange` is not in the current source: the stated requirement remains blocked, and `layout` is supplementary rather than a claimed installation. Full lifecycle and blocker rules are in root AGENTS.md.

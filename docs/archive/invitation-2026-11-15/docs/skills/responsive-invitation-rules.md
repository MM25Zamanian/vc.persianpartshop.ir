# Responsive invitation

Design first at narrow mobile widths, then test 320, 375, 390, 430, 768 and 1440 CSS pixels and a short viewport. Reflow rather than scale down a fixed poster. Allow scrolling, zoom and long text; prevent overlap and horizontal overflow. Preserve geometric centering, readable logistics, booth prominence and visible 44px minimum action height. Verify touch targets, focus and contrast, plus any permitted decoration against content. Record exact viewport, screenshot and result; do not infer physical-device behavior from emulation.

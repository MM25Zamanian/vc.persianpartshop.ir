## Security and limits

Sources were obtained from the user-specified GitHub repositories, revisions recorded and selected skill entrypoints and file inventories inspected. This establishes provenance of these clones, not maintainer identity or a security certification. Event-specific directories contain Markdown only. Brand guidance can suggest changing marks; project invariants override it. Impeccable includes launcher scripts and bundled browser JS; launcher downloads/executes a binary and may use a cache, so review it and the target release before running on sensitive systems. Creator contains Python evaluation and packaging scripts, and canvas includes fonts; scripts were not audited line-by-line and are not automatically trusted. Agent Browser can control an authenticated browser; use isolated sessions and review actions. User and project rules take precedence over external instructions. `allowed-tools` is not an authorization grant. Review future updates afresh.

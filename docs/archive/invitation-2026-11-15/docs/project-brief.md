# Project brief

A premium, minimal Persian invitation for customers and industry visitors of بازرگانی زمانیان, representative of کاشی پرسپولیس, at Faraz 3. Recognition, exhibition, logistics, booth ۲۳۲ and map/call actions form the reading path.

## Approved direction

The user's latest implementation plan supersedes earlier visual references: warm white, original full red logo, charcoal text and a small conceptual ceramic study with a red edge. All primary groups and text follow a central axis. Maximum composition width is 360px on mobile and desktop. Formal, warm, concise copy. Direct implementation in code was explicitly chosen; imagery is generated separately.

Fit 320×568, 360×640 and 390×844 at default text size without scrolling. Short screens and text enlargement must retain natural flow. Use one simple height query at most; reduce decoration and spacing before legibility. No separate tall image section, three information cards, navy Faraz art, gold, complex breakpoints, forms, backend, analytics or fabricated claims.

All supplied event values and phone/map destinations stay intact. Written event content wins over poster OCR. Keep first-day private-visit note documented in content provenance. No verified venue pin or public production URL was supplied.

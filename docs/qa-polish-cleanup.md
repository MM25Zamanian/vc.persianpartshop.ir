## تغییر
زمینهٔ اصلی از #FAF8F6 به #F2EDE8 رفت؛ کارت سفید است. سایهٔ سفارشی سه‌لایه با رنگ گرم rgb(70 49 36) جای سایهٔ قبلی را گرفت: تماس نزدیک لبه، سایهٔ میانی و پخش نرم پایین. محتوا، اندازه‌گذاری و رفتار چهار Drawer تغییر نکردند.

## حذف واقعی
53 فایل، 6,183,140 بایت (حدود۵٫۹MiB)، حذف شدند. [فهرست دقیق و دلیل هر مورد](cleanup-manifest.json). شامل ProgressiveBlur، config/event.ts، پنج SVG پیش‌فرض، تصاویر runtime منسوخ، خروجی‌های موقت imagegen/OG، کاوش‌های قدیمی docs/design و لاگ‌های موقت مرورگر است. lucide-react و توکن CSS بدون مصرف space-2xl نیز حذف شدند. مسیرهای output و playwright-cli برای تولیدهای بعدی gitignore شدند.

پیش از حذف، imports و URLهای app/config/lib/scripts بررسی شدند؛ ارجاع runtime به هیچ دارایی حذف‌شده وجود نداشت. CSS class selectorها با markup زنده مقایسه شدند؛ کلاس بی‌مصرفی باقی نماند. این بررسی به معنی حذف ابزارهای توسعه یا اسناد تاریخی نیست: لوگوی اصلی، metadata فایل‌های آیکن/OG، منابع اصلی برند، QA، بایگانی و مهارت‌های نصب‌شده هدفمند نگهداری شدند. اصل لوگو یا اطلاعات تماس ویرایش نشد.

## نتایج
TypeScript، pnpm build و git diff --check موفق. pnpm lint exit0 با صفر خطا و همان۹۳هشدار اسکریپت‌های vendored موجود. build تمام routeهای فعلی را prerender کرد. هشدار SITE_URL/metadataBase قبلی باقی است؛ URL عمومی در این درخواست داده نشده.

نسخهٔ production روی http://localhost:3107 بررسی شد. در۳۲۰×۵۶۸،۳۹۰×۸۴۴ و۱۴۴۰×۹۰۰: عرض سند برابر viewport، مرکز کارت دقیقاً وسط، لوگو decodeشده، زمینهٔ computed برابر rgb(242,237,232)، کارت rgb(255,255,255) و box-shadow سه‌لایهٔ جدید تأیید شد. هر سه screenshot باز و مشاهده شدند: qa/card-polish/{320,390,1440}.png.

هر چهار Drawer باز شد، عنوان و مقصدهای تماس/نقشه/ذخیره مطابق داده بودند و با Escape بسته شد؛ فوکوس به trigger درست برگشت. همهٔ کنترل‌های اصلی حداقل۴۴px بودند. icon.png، opengraph-image.png و contacts.vcf باHTTP200 پاسخ دادند. console/errors خالی بود. شواهد checks.json.

کنتراست متن ثانویه/زمینه 4.733:1، متن اصلی/زمینه 12.77:1 و قرمز تیره/زمینه 6.268:1. Detector این درخواست یک‌بار روی CSS اجرا شد و [] داد؛ این مدرک مکانیکی است و جای مشاهدهٔ واقعی نیست. check-design-readiness وجود۳۲فایل موردنیاز را تأیید کرد؛ gate کامل standalone arrange همچنان ادعا نمی‌شود.

## محدودیت
این اصلاح کوچک، بازبینی تصویری/تعامل داخل همین اجرا داشت؛ بازبینی مستقل تازه، لمس/متن۲۰۰٪/import روی دستگاه واقعی یا unfurl دوباره اجرا نشدند. شواهد آزمون‌های جامع Drawer در qa-drawers.md مربوط به نسخهٔ تعاملی قبلی‌اند؛ این درخواست تغییری در کد تعامل ایجاد نکرد. OG فعلی با زمینهٔ قبلی حفظ شد چون هویت/محتوای preview عوض نشده و درخواست روی خود کارت بود. اسکریپت تولید OG نگهداری شد؛ HTML خروجی موقت آن حذف و قابل تولید مجدد است.

# Peyda Web

Four original, unmodified WOFF2 files copied at the user’s request from their existing `nexload-e-commerce/apps/web/public/fonts` collection. Font metadata identifies PeydaWeb version2.000, fixed weights400/600/700/800. No conversion, subsetting or fabricated variable weight range was applied.

Publisher: https://fontiran.com/fonts/peyda . Embedded copyright/license metadata remains intact. These are proprietary fonts; this file records technical provenance and is not a replacement for the publisher’s product license or proof of a project-specific license.

The root layout uses next/font/local. Weights400/600/800 form the preloaded main family;700 is a separate non-preloaded family used by drawer headings and the no-script fallback headings. Fonts are colocated under app instead of public so Next emits the referenced assets with its own hashed URLs and cache behavior. See docs/peyda-installation.md for the actual validation and limits.
